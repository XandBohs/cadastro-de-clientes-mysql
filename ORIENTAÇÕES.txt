1- Criar o projeto no Supabase
2- Executar o script supabase/schema.sql no SQL Editor
3- Configurar as variáveis NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY e SUPABASE_SERVICE_ROLE_KEY na Vercel
4- Fazer novo deploy depois de salvar as variáveis
5- Instalar dependências com npm install
6- Rodar o projeto com npm run dev
7- Fazer deploy do frontend na Vercel
